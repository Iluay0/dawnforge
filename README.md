# Dawnforge

Upgrades FFXIV modpacks (.ttmp, .ttmp2, .pmp) to Dawntrail, like TexTools' "Upgrade Modpack".

## Use

Download the build from releases and run it. Set your game folder, add your modpacks, press Convert all.

Terminal:

    dawnforge <modpacks...> -o <output folder> --game <game path>

Uses TexTools' xivModdingFramework. GPLv3.
